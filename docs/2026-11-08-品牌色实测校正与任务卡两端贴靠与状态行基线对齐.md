# 2026-11-08 品牌色实测校正与任务卡两端贴靠与状态行基线对齐

## 三项修复

**1)顶栏品牌主题色误差校正(采样徽标图块真实底色)**

- 原配置色是早期文字徽标时代的近似值,与官方图标图块的**实际底色**偏差明显
  (尤其猎聘:配置红色 #d8262c,图块实为**橙色**),顶栏整条铺色后一目了然;
- 用 PIL 采样 3x 徽标图四角得到真实底色并更正:
  - Boss直聘 `#00a6a7` → **`#15b3b3`**(图块实色)
  - 猎聘 `#d8262c` → **`#ff6400`**(图块实色)
  - 前程无忧 `#ff6000` → **`linear-gradient(135deg, #fc8f1c, #e7014b)`**
    (图块本身为对角渐变,顶栏背景同样用渐变,与图块观感一致)
- `PLATFORM_LOGOS.color` 更名 `bg`(承载 CSS 背景值,可为渐变串),
  顶栏背景、文字徽标回退底色共用;`platformLogo()` 回退对象与两处模板
  绑定同步更名,旧值引用清零。

**2)最近任务卡片贴顶 + 底部贴底(纵向拉伸)**

- `.task-card` 改 `flex: 1`:顶部紧随「发起抓取」卡(贴顶保持),
  底边贴住左栏底部(底部也贴底);
- `.task-scroll` 由固定 180px 改 `flex: 1; min-height: 180px`:行区高度随
  左栏剩余空间伸缩(可显示更多行),不足 5 行时维持 180px 并内部滚动;
  行高 36px 锁定不变。

**3)状态栏平台文字偏低修正**

- `.ts-item` 由 `align-items: center` 改 **`align-items: baseline`**:
  平台名(13px)与「空闲」/进度(12px)、计数徽章(11px)共用一条文字基线,
  消除"平台文字比相邻元素低"的观感;
- 圆点无文本基线,`align-self: center` 单独垂直居中。

## 验证

- `node --check` 通过;`\.color`/旧色值引用清零;徽标底色采样脚本实测
  (boss/liepin 四角一致,51job 确认对角渐变)。

  不参与 background-color 过渡(渐变即时切换,平色间仍平滑)。
