# 2026-11-08 徽标半透明态与状态白框与任务卡贴顶与间距缩减

## 四项改动

**1)平台徽标未选中/未悬停时半透明**

- `.top-plat .plogo` 默认 `opacity: .5`,悬停/选中恢复不透明(配合此前的
  transform 放大,选中态=放大+不透明,未选中态明显退后);
- 透明度只作用于徽标图,指示灯是徽标的兄弟节点**不随透明变暗**,
  运行/异常灯保持醒目。

**2)状态区包白色圆角框**

- 顶栏中心状态区套上与品牌区同款的白色圆角卡(`var(--card)` + 10px 圆角
  + 浅阴影,absolute 居中改 `translate(-50%, -50%)` 垂直居中),
  **内部不受品牌主题色影响**;
- 内部文字随之恢复常规配色(平台名 var(--text)、进度 var(--text2)、
  空闲 var(--text3)),上一轮为彩色底加的"白字+绿点白环"补丁移除。

**3)最近任务卡片贴顶**

- 再次去除 `margin-top: auto` 贴底逻辑:左栏卡片从顶部堆叠,
  「最近任务」紧随「发起抓取」之后(flex gap 8px),底部留白。

**4)表格区左边界左移**

- 左栏右 padding 12 → 6,与表格区间隔 14px → **8px**(与 .side 卡片间
  8px 间距节奏一致);左栏宽度维持 356 不变。
