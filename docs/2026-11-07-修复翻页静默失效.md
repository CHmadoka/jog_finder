# 2026-11-07 修复:翻页静默失效(根因)与设置词条标签样式

## 根因与修复:岗位表翻页从未生效

- **根因**:app.js 的 setup return 列表遗漏了 loadJobs。
  模板中 @current-change="loadJobs" 引用不到该函数,被编译为 undefined 处理器,
  el-pagination 内部页码状态照常切换(激活页码会动),但 current-change
  回调静默不执行——不发请求、数据不翻页。第一版起即存在;
  @size-change="reloadJobs" 因 reloadJobs 在返回列表中而正常,颇具迷惑性。
- **修复**:loadJobs 加入返回列表。
- **取证方法**:无头浏览器 + fetch 拦截确认点击页码后零请求;用与主应用完全
  一致的最小复刻页证明同样写法可正常触发,排除 Element Plus/浏览器因素;
  再对模板引用与 setup 返回列表做全量比对,锁定缺失绑定。
  已全量比对,其余引用(插槽变量/对象属性/样式字面量)均无缺失。

## 其它变更

- 岗位设置管理弹窗中,词条恢复为原来的 el-tag 标签样式(行内小字方案弃用)。

## 验证

- 无头浏览器实测:点击页 2 首行数据变化、激活页码 2;切换每页 50 条生效;
  unittest 64 项通过。
