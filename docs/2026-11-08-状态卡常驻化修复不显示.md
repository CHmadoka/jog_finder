# 2026-11-08 状态卡常驻化(修复"状态卡没有显示")

## 根因

状态卡自迁顶栏起沿用了「全空闲整卡隐藏」的设计(`v-if="runningPlatforms.length"`),
空闲时不渲染任何内容;而旧版左栏状态卡是**常驻**的(空闲显示"平台名 空闲")。
实测 `/api/tasks/status` 接口与前端轮询链路均正常(空闲时正确返回
`running:false`),两轮"状态卡没显示/没生效"实际都是空闲态下卡片整体不渲染。

## 修复:状态卡常驻 + 段列表重构

- 卡片去掉 `v-if`,**空闲也显示**:当前平台行 = 灰圆点 + 平台名 +「空闲」
  + 最近一次进度文本(有则显示,如 `[任务5] 完成:…`);
- 数据源由 `runningPlatforms`(仅运行中平台)重构为 `statusSegments`:
  **当前平台恒在首位**(运行中 → 呼吸圆点+计数徽章+进度+悬停组合浮层;
  空闲 → 上述空闲态),其后追加其它运行中平台(多平台并发同屏保留);
- `runningPlatforms` 计算属性随之删除(引用清零);新增 `.ts-idle` 样式,
  `.status-card` 注释同步为常驻语义。

## 验证

- `node --check` 通过;`/api/tasks/status` 实测返回结构正确;
- `runningPlatforms` 引用清零确认。

## 备注

- 纯前端改动,刷新即生效(建议 Ctrl+F5);
- README「抓取操作」步骤 4 描述同步为常驻语义。
