# 2026-11-08 抓取按钮承载提示与全局边距统一

## 两项视觉反馈

**1)抓取栏拥挤:黄字提示并入按钮**

按钮下方原本常驻两行提示(橙色"请先选择…" / 灰色"结果存入数据表「XX」"),
内容多时左栏拥挤。改为:

- **禁用时按钮文字即原因**:未选岗位设置/已存条件时,灰色按钮直接显示
  "请先选择岗位设置"(startHint),不再单独占一行
- **存入表信息转入按钮 tooltip**(`span` 包裹解决禁用按钮不触发 tooltip),
  并在不满足启动条件时附带原因
- 两行提示删除,节省的垂直空间交给按钮上边距(10px),抓取栏呼吸感恢复
- `.start-hint` 样式与 DOM 一并清除(已无引用)

**2)左右栏边距统一**

左栏此前收紧为 `padding: 10px 12px`,但右栏仍是 `14px 14px 14px 0`——
顶栏之下两侧首行内容不齐、整体观感不统一。右栏改为
`padding: 10px 12px 10px 0`(左侧由左栏右 padding 提供 12px 间隔),
与最近任务卡片的顶部边距、左栏卡片体系完全对齐。
