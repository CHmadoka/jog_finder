# 2026-11-08 平台按钮迁顶栏与最近任务贴靠与条件管理入组合框

## 三项界面重构

**1)平台切换按钮迁至顶栏(logo 右侧)**

- 左栏「发起抓取」卡内的平台按钮区(`.platform-switch`)整体移除,迁到顶栏
  logo 右侧,与品牌区之间加**竖线分隔**(`.topbar-divider`);
- 按钮改为**纯圆角徽标图标**(无文字,平台名走悬停 title;徽标仍是 30px
  `.plogo`,与 gen_logos.py 的 CSS_SIZE 绑定不改动):
  - 悬停 `scale(1.15)` 放大(transform 不参与布局,不推挤邻元素),
    **选中保持同样放大**作为选中态;
  - 徽标**右上角指示灯**保留原语义:运行绿 / 空闲灰 / 最近任务异常红;
  - 最近任务结果临时状态(完成绿/异常红)由原边框+inset 描边改为**外圈
    阴影环**——纯图标按钮被整幅徽标图片铺满,inset 描边会被盖住;
- 顶栏 logo 旁的说明文字(「已登录浏览器自动抓取岗位 · 健康状态」)移除,
  `healthText` 与 onMounted 的 /health 探活死代码一并清理。

**2)最近任务卡片贴靠抓取卡**

- 「最近任务」卡片去除 `margin-top: auto` 贴底逻辑,改为**紧随「发起抓取」
  卡片之后**(左栏 flex gap 8px 标准间隔),卡片高度不变(5 行 180px);

**3)已存条件管理入口入组合框 + 去摘要说明**

- 「选择条件」对齐快速抓取的交互:下拉选择器包进 `.table-combo`,
  「管理条件」链接改为组合框内**齿轮按钮**(tooltip:管理筛选条件);
- **去除选择条件下方的条件摘要说明区**(`.cond-summary`,含未选时的
  「点右上角…创建」提示与「编辑此条件」链接——管理入口已在齿轮按钮内);
- 两种模式内容区不再强制 232px 等高(`.grab-mode-area` 移除,改为内容
  自适应):原固定高度是为贴底任务卡保持间距,任务卡改贴靠后不再需要,
  已存条件模式卡片随内容变矮,与快速模式结构平行。

## 验证

  psw-item / cond-summary / grab-mode-area 引用清零确认(纯前端改动)。
