# 修复切换平台导致左栏卡片宽度跳动

日期:2026-11-07

## 现象

点击某个平台(如 Boss直聘)后,左栏所有卡片看起来一起变宽/变窄。

## 根因

不是卡片自身宽度变化,是**滚动条忽隐忽现**:

- 左栏 `.side` 用 `overflow-y: auto`,只在内容超高时才显示滚动条;
- 左栏内容高度随平台变化——「最近任务」卡片在没有任务记录时(105px)比
  有任务记录时(97px)高 8px,因为空态文案占位更多;
- 一旦窗口高度恰好让左栏处在「刚好不需要滚动条」的临界值,切换平台就会让
  滚动条出现或消失,内容区宽度随之变化约 15px,整列卡片跟着一起伸缩。

实测(1500×820)`scrollHeight` 在 boss 与 51job 间相差 8px(793 vs 801)。

## 改动

`.side` 改为 `overflow-y: scroll` + `scrollbar-gutter: stable`:
滚动条槽位常驻,内容高度变化不再影响内容区宽度,卡片宽度恒定。
代价是任何窗口高度下都预留滚动条宽度(396px 栏内卡片由 368 → 360px),
属于稳定优先的取舍。

## 验证

无头浏览器(禁用覆盖式滚动条)在 1500×860/820/800/780/700 五种高度下,
依次切换 Boss → 前程无忧 → 猎聘 → Boss:卡片宽度全部恒为 360px,无跳动。

## 备注

纯前端 CSS 改动,刷新即生效(建议 Ctrl+F5)。
