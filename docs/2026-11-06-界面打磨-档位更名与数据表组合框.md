# 2026-11-06 界面打磨:档位更名、数据表组合框与自动命名、弹窗表格轻量化

## 变更清单

1. **"岗位档位"更名为"岗位设置"**:菜单项、抓取面板字段与占位文案、设置管理弹窗、
   条件管理表单/摘要/列表列头、确认话术等全部用户可见文案同步更名(后端字段名不变)。
2. **数据表组合框**:工具栏中数据表下拉与设置(齿轮)按钮合并进同一个圆角边框容器
   (下拉无边框化 + 分隔线),右上角"数据表管理"菜单入口移除(唯一入口即该齿轮);
   当前表为默认表时,下拉框后显示"默认"小标签。
3. **新建数据表自动命名**:新建不再要求输入表名,一键创建自动命名为
   「数据表_{id}」(标识符自动 tbl_{id}),后续可通过"编辑"重命名;
   编辑态才显示表名/标识符输入框。
4. **弹窗表格轻量化**:数据表管理、岗位设置、筛选条件管理三个弹窗内表格
   去掉重网格边框(border),表头透明背景 + 灰色小字 + 细分隔线,悬停浅色,
   视觉更轻(`.dlg-table` 统一样式)。
5. **修复编辑未生效的缺陷**:`saveTable`/`saveGear` 更新时 PUT 打到了集合路由
   (`PUT /tables`、`PUT /gears`,405),导致任何编辑保存都不生效——
   现已带上资源 id(`PUT /tables/{id}`、`PUT /gears/{id}`);编辑按钮改用
   `editTable/editGear` 函数(Object.assign)填充表单。
6. **后端**:`TableIn.name` 改为可缺省,`POST /api/tables` 缺省时自动命名。

## 验证

- 冒烟:无表名建表自动命名「数据表_2」;默认表重命名为主表再改回,均成功。
- unittest 64 项全部通过。
