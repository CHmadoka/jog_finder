# 2026-11-08 顶栏品牌主题色与徽标高清源与状态卡移回左栏

## 四项改动

**1)顶栏平台徽标放大发虚修复**

- 悬停/选中放大用 transform 缩放位图,1x 源图(30px)放大 15% 即发虚;
- 顶栏徽标 img 改为**直接加载 @2x 源图**(`PLATFORM_LOGOS` 新增 `img2x`
  字段,文件已由 gen_logos.py 生成):30px 盒常显即 0.5 倍下采样锐利,
  transform 放大到 ~34.5px 仍在 2x 位图分辨率内,不再发虚;
- 任务行 16px 小徽标维持 srcset 逻辑不变。

**2)顶栏铺选中平台的品牌主题色**

- 选中平台后顶栏背景 = 该平台品牌色(boss 青 #00a6a7 / 51job 橙 #ff6000 /
  猎聘红 #d8262c),切换平台时背景 0.3s 平滑过渡;
- **logo 与平台按钮所在的圆角区不受影响**:品牌区+竖线+三个平台按钮包进
  `.brand-zone` 白底圆角卡(浅阴影),在品牌色顶栏上保持原观感;
- 未知平台回退空字符串 → 白底。

**3)最近任务卡片恢复贴底**

- 恢复 `margin-top: auto` 把「最近任务」推到左栏底边(上一轮"紧随抓取卡"
  方案撤销);模式内容区维持内容自适应高度,切换模式只改变任务卡上方间隔。

**4)运行状态卡移回左栏(最近任务卡上方)**

- 顶栏中心状态区(上轮迁移后实测未达预期)整体移除,状态展示移回左栏:
  `<div class="card status-card">` 插在「发起抓取」与「最近任务」之间,
  **仅运行时出现**——任务卡贴底的 auto 外边距把它恰好推到任务卡正上方,
  空闲时整卡隐藏不占位;
- 保留上轮的多平台并发同屏(每平台一段)与悬停组合进度浮层,布局适配
  窄栏:每段上行「圆点+平台名+发现/入库/跳过徽章(左推右)」、下行进度
  单行省略;浮层锚定平台段向下展开,盖在任务卡上(z-index 60);
- 废弃样式清理:`.top-status` 顶栏居中定位规则删除,`.ts-item` 改列内
  块级布局,新增 `.ts-line` 行容器。
