## 变更

`README.md` 使用流程中"一键启动"一节,删除对 **`停止.bat`** 的引用
(该脚本文件此前已不存在,文档残留旧说明)。

## 当前停止方式

- **关闭 `job_finder-server` 控制台窗口**即停止服务——依赖
  `app/main.py` 的控制台生命周期绑定(见
  `2026-11-07-服务生命周期绑定控制台窗口.md`),窗口关闭时整个
  服务进程树随之退出;
- 或在窗口内按 Ctrl+C 走优雅关闭。
