# 标题词条高亮(与入库匹配规则对齐)

日期:2026-11-07

## 背景

核实入库匹配规则,确认标题参与判定:

- `app/filter/__init__.py` `evaluate_job`:词条与标题做大小写不敏感的
  子串匹配,标题未命中任何档位词条时记不符原因"标题未直接命中档位"。
- `app/filter/rules.py` `_TITLE_RULES`:兼职/实习/资深/总监等规则仅扫标题。

因此词条高亮范围扩展到标题,与入库判定口径一致。

## 实现

- `web/app.js`:高亮逻辑抽为公共 `highlightText(text)`(HTML 转义 →
  词条长词优先、大小写不敏感替换 `<mark>`,保留原文大小写);
  `highlightedTitle` 与 `highlightedDesc` 共用;`hitKeywords` 命中判定
  同步改为大小写不敏感(与 lower() 匹配一致)。
- `web/index.html`:抽屉标题从 `:title` 纯文本属性改为 `#header` 插槽
  `v-html` 渲染(标题可换行、词条高亮);新增 `.drawer-title` 与其
  `mark` 样式。
