# 2026-11-07 城市多选(省市级联)与默认翻页上限 10

## 变更清单

1. **城市改为多选标签项(省市级联选择)**:
   - 新增 `CityPicker` 组件(与 KwEditor 同容器风格):已选城市以可删标签展示,
     `el-cascader` 按 省 → 市两级行政级别分级选择,选中即追加标签;
   - 级联数据 `web/cities.js`(31 省 / 337 市,生成自 china-division@latest
     npmmirror 镜像;重新生成用 `scripts/gen_cities.py`;直辖市"市辖区"虚级
     归一为省短名,"省直辖县级行政区划"跳过);
   - 抓取调度改为「词条 × 城市」组合循环(空城市列表 = 全国),
     组合之间保留拟人间隔;任务消息为"完成:N 个词条×M 个城市,…";
   - 已存条件城市字段存逗号分隔多城市串(兼容旧单值数据,读取时自动拆分),
     条件摘要与任务详情卡以顿号展示(空 = 全国);
   - **未收录城市启动前明确拒绝**:各平台城市代码表有限(Boss/51/猎聘各
     ~20 城),未收录城市不再悄悄回退全国(误导),`BasePlatform.
     supported_cities()` 暴露支持集,启动时 400 并列出支持城市。
2. **默认每词条翻页上限 10**:`.env` / `.env.example` / `config.
   MAX_PAGES_PER_TASK` / 前端 `grab.max_pages` 默认值统一 10。
3. **顺带修复两个后端缺陷**(多城市持续抓取场景下必现):
   - `_db_update_existing` 未命中返回 0 与"命中但无字段变化"返回 0 无法区分,
     重复岗位会被误判为新岗位走 INSERT → 唯一键冲突使整个任务中断;
     现未命中返回 -1,`_process_one` 以 `>= 0` 判定已存在;
   - `_run` 兜底异常分支 `status, message = f"..."` 把字符串解包成字符,
     改为 `("error", 消息)` 元组。
