# 2026-11-08 状态区定居顶栏中心与表格区左缘缩减

## 两项改动

**1)状态区移到顶栏中心(常驻)**

- 左栏「运行状态」卡整体移回顶栏中心(`.top-status` absolute 居中,不参与
  顶栏 flex 布局)——上轮"移回左栏"撤销;内容沿用刚验证过的常驻段列表
  (`statusSegments`:当前平台恒首位 + 其它运行中平台),不再"全空闲隐藏",
  杜绝此前两轮"看不到状态"的观感问题;
- 段布局适配顶栏横排:空闲段 = 灰点 + 平台名 +「空闲」;运行段 = 绿点 +
  进度(超宽省略,max 220px)+ 发现/入库/跳过徽章;悬停运行段向下浮层
  展开任务组合(浮层随顶栏 z-index 10 层级盖在页面内容上);
- 顶栏铺品牌主题色后中心区文字改白色(平台名/进度/空闲),运行绿点加
  白环与品牌色底隔离;计数徽章自带浅色底不受影响。

**2)表格区左缘缩减(适配整体)**

- 状态区离开左栏后,按既定"迁出即让位"模式再次收窄左栏:376 → **356**
  (表格区左缘整体左移 20px),与右栏间隔维持 14px 不变;
- 356px 下复核:任务行(编号+徽标+状态+三个统计标签+时间 ≈313px)与
  抓取卡各控件在 332px 内容宽内均完整容纳,统计标签极端长文本由
  `.task-stats` overflow hidden 兜底。
