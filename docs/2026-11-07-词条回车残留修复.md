# 2026-11-07 修复:词条回车创建后输入文本残留

## 根因

el-select(multiple + filterable + allow-create)在 2.7.3 下,回车创建词条后
输入框中的文本不会清空(实测复现:创建 Java/服务端后输入框分别残留原文)。
筛选条件弹窗的避开/优先行业选择框为同款组件,存在同样问题。

## 修复:自定义"标签输入器"组件 KwEditor

以"标签 + 回车添加输入框"的组合替代上述四处 allow-create 选择框:
- 回车添加后**无条件清空输入框**(重复词条去重但也清空);
- 标签可点 × 删除;样式与原 el-select 的标签观感一致(小号描边标签);
- 应用位置:岗位设置创建行、岗位设置行内编辑、筛选条件的避开/优先行业。

顺带改进:新建设置改用独立表单(gearNew),与行内编辑互不干扰,
添加按钮不再需要在编辑期间禁用。

## 验证(无头浏览器)

- 创建行:回车两次,输入框残留均为空,标签累计 2 个;
- 添加设置成功(POST /gears),新行正确显示词条标签;
- 行内编辑:回车添加词条即清空(标签 3 个),保存触发 PUT 且行内容更新;
- 测试数据已清理;unittest 64 项通过。
