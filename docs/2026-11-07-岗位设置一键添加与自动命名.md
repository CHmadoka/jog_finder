# 2026-11-07 岗位设置添加改为一键建项 + 自动命名(对齐数据表)

## 变更清单

1. **添加交互对齐数据表**:岗位设置管理的顶部输入行(名称 + 词条 + 添加按钮)
   改为单个「添加岗位设置」按钮;点击即新建表项,随后自动对该行进入行内编辑,
   再填写名称与词条。移除了独立新建表单 `gearNew`。
2. **自动命名**:名称缺省由后端自动取「新岗位设置_n」(n 从 1 递增,
   取首个未占用序号,被手工占用的序号会跳过);词条可缺省(空列表)。
   实现与数据表 `create_table` 完全同构(占位名 `__pending__` 落行后补名,
   规避 name 唯一非空约束)。
3. **保存校验**:行内保存时空名称仍被拦截(前端提示「请填写设置名」,
   后端 `PUT /api/gears/{id}` 空名返回 400「设置名不能为空」);
   非空重名仍 409。词条留空保存即为「无词条」设置。

## 涉及文件

- `app/models/schemas.py`:`GearIn.name` 允许缺省(默认空串)。
- `app/api/gears.py`:`create_gear` 自动命名;`update_gear` 空名拒绝。
- `web/app.js`:`createGear` 改为一键建项 + 自动进入行内编辑;删除 `gearNew`。
- `web/index.html`:岗位设置弹窗顶部改为「添加岗位设置」按钮 + 说明文字。
