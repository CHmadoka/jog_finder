# 2026-11-07 异常面板收起与整行阴影、抽屉文本可选中、福利标签拆分

## 变更清单

1. **异常面板点击空白收起**:抓取异常悬浮卡片(左下角二级面板)此前只能点
   「收起」按钮关闭;现注册全局 `document click` 监听,点击面板与唤起按钮
   以外的任意空白处自动收起(面板内部点击不误关)。
2. **整行阴影替代悬停下划线**:异常行(带链接的)原先是链接文字悬停显示
   下划线;改为整行可点、悬停时整行浮起阴影(`box-shadow` + 白底圆角,
   底部虚线在悬停行内隐藏),去掉文字下划线。点击目标从消息文本扩大到整行。
3. **详情抽屉文本可选中**:全局禁选规则此前波及岗位详情抽屉;现职位描述
   (`.drawer-desc`)与基础信息表格(`.el-descriptions__body`)显式放开
   `user-select: text; cursor: text`,可正常复制。
4. **福利标签拆开**:Boss 抓取的福利以顿号「、」连接(如
   `餐补、团建聚餐、带薪年假`),原 split 只认 `[,,;;]` 导致整串挤在一个
   标签;拆分逻辑移入 `welfareTags` computed,分隔符扩展为
   `/[,，;；、]+/` 并过滤空片段,每个福利独立成标签。

## 涉及文件

- `web/app.js`:`onDocClick` 全局收起监听(挂载/卸载成对注册);新增
  `welfareTags` computed 并导出。
- `web/index.html`:异常面板行结构(整行点击/标题提示)、`.ep-row` 悬停阴影、
  抽屉可选中样式、福利标签改用 `welfareTags`(key 改索引防重名冲突)。
