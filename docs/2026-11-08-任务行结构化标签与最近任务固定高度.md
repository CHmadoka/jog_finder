# 2026-11-08 任务行结构化标签与最近任务固定5行高度

## 两项反馈修正

**1)结束的任务行改为结构化小标签**

原行内显示的是一整段结束消息("完成:1 个词条×1 个城市,发现 20,新入库 10…"),
信息密度低且不可扫读。改为三个小标签(数据取 TaskOut 结构化字段,不解析文案):

- `m词条`(keywords 按竖线计数)
- `n城市`(city 逗号计数;空 = `全国`)
- `a/b入库`(saved/found,绿色高亮;异常中断的任务同样显示已完成的部分)

悬停仍有完整 message 的 tooltip;运行中的行保持文本(进度),不受影响。
标签组 `overflow: hidden` 不换行(换行会破坏固定行高),完整信息进详情弹窗。

**2)最近任务卡片高度固定为恰好 5 行**

上一版用 flex:1 让卡片"填满左栏剩余高度"——左栏内容变高时它仍被压缩,
这不是用户要的"始终保持 5 行"。改为:

- 卡片 `flex: none`(退出左栏 flex 拉伸),行区 `.task-scroll` 固定高度
- 精确行高:el-tag small 24px + 行 padding 12px = 36px,前 4 行另有 1px
  虚线分隔 → `height: 184px` 恰好完整显示 5 行
- 高度不再随左栏任何内容(城市标签/词条/条件摘要)变化;第 6 行起在
  行区内部滚动 + 触底懒加载(上一轮已有)
