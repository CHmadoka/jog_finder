# 详情页去装饰化:克制高级风

日期:2026-11-07

## 反馈

不够高级;表格原始;标题不需要竖条前缀;渐变分割线原始不好看;福利标签
要回原样式。

## 设计转向:去装饰、留白与灰度分层(premium = 克制)

- **标题**:删除渐变竖条前缀,字号加大到 17px,靠字重与字距分层。
- **header 下边缘**:删除彩色渐变线,改为**发丝线**(1px,rgba 7% 黑),
  且左右各留 20px 内缩——低调但可见的分隔。
- **信息表格去网格化**(spec-sheet 风格):去掉全部竖线/外框/label 底色/
  投影,label 改灰色常规字重,行间仅极淡横线(末行无线)。
- **福利标签**:删除胶囊化覆盖,恢复 Element 默认样式。
- **区块标题**:去竖条,12px 灰字 + 字距,靠留白分层。
- **按钮**:去渐变/hover 上浮,仅适度圆角 8px。
- **备注 callout**:柔化(去外框,仅左侧 3px 警示条)。
- **描述区**:极淡底 + 发丝边框。
- 保留 body 细滚动条。

## 备注

- 纯前端样式,刷新即生效(建议 Ctrl+F5)。
