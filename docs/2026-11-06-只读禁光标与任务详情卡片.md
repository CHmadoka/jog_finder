# 2026-11-06 交互打磨:只读文本禁用光标、任务详情卡片、管理弹窗美化

## 变更清单

1. **禁用只读内容的光标/选中闪烁**:全局 `user-select: none` + `cursor: default`,
   悬浮提示(el-popper)、标签(el-tag)、异常浮标、所有非编辑只读文本不再出现
   文本光标与拖选闪烁;仅输入框/文本域保留文本选择与输入光标。
   (注意:岗位描述等只读文本因此不可拖选复制,如需复制能力可再放开。)
2. **最近任务可点击查看详情**:任务行增加悬停高亮与手型光标,
   点击打开"任务详情"卡片:平台/状态/起止时间(未完成为"—(中断/中止)")/
   匹配词条(标签化)/城市/薪资范围/发现/新入库/跳过/跳过原因明细/结束消息/条件快照 JSON。
3. **管理弹窗美化(数据表管理、岗位设置管理,筛选条件管理同步)**:
   - 表头区压缩为一行:岗位设置改为"设置名 + 词条 + 添加/更新 + 取消"单行表单
     (原独立标题行与多行 el-form 移除);数据表编辑态同样单行化
     ("重命名 #id + 表名 + 标识符 + 保存 + 取消");
   - 列表放入带边框圆角的 `.dlg-list` 容器,边界清晰;
   - 操作按钮改为胶囊样式 `.mini-btn`(无边框圆角、悬停浅色底,
     主色/警示橙/危险红三态),替换原 link 按钮。
