# 界面状态本地记忆:存入表/浏览表/浏览平台/任务筛选

日期:2026-11-07

## 需求

- 存入目标表(左栏)与浏览数据表(右栏)**各自独立记忆**;
- 浏览的平台筛选、任务筛选也记忆,下次打开自动恢复。

## 实现(web/app.js)

新增 localStorage 键:`jf_grab_table`(左栏存入表)、`jf_view_platform`
(右栏平台)、`jf_view_task`(右栏任务);原 `jf_current_table`(右栏浏览表)
保留。四项均以 `watch` 统一落盘——**程序性变化同样被记忆**:删除任务后
退出过滤(置空即移除键)、删除表后回退默认表,都不会残留脏值。

恢复(onMounted,按序校验):

- 浏览平台:须在平台列表中,非法值忽略(空=全部平台);
- 浏览表 / 存入表:须在数据表列表中,否则回默认表;
- 任务筛选:候选(最近30条)加载后校验——不在候选中(平台不符/已删除/
  超出30条)则放弃恢复,避免打开页面即空列表;恢复时联动校正平台。

## 备注

- 纯前端改动,刷新页面即可生效,无需重启服务。
