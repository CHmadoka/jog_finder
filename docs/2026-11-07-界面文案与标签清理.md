# 界面文案与标签清理(词条标签/未分析/提示语)

日期:2026-11-07

## 改动

1. **岗位详情标签区**:
   - 删除「词条: <任务全部词条长串>」标签(冗余且过长);
   - 命中词条标签去掉"命中: "前缀,直接显示词条本身(悬停提示保留)。
2. **"未分析"彻底删除**(fit 为 null 的展示口径弃用):
   - 详情抽屉不再显示"未分析"标签(仅有 契合/不符 两种);
   - "无备注"提示改为「判定契合」;
   - `/jobs/stats` 接口移除 `unknown` 字段,前端 stats 同步移除。
3. **文案修正**:
   - 左栏「存入数据表(与右侧浏览无关)」→「存入数据表」;
   - 「薪资范围(K/月,单边可缺省)」→「薪资范围(K/月)」——实际两端
     都可留空(不限),原"单边"表述不准确。
4. **「限定词条」作用说明**(原表述含糊):
   - 快速抓取:label 改「限定词条(只抓这一个词,可选)」,悬停提示
     "不改变所选岗位设置:填了则本次只抓这一个词条(适合先试抓一个词
     看效果);留空则抓取该设置的全部词条";placeholder 同步改写;
   - 条件管理弹窗的限定词条输入同样加悬停说明。
