# 2026-11-07 管理弹窗重构:无表头行式列表、行内编辑、删除即清数据

## 变更清单

1. **数据表管理 / 岗位设置管理弃用 el-table,改为行式列表**:
   - 无表头行、无多余列(ID/标识符列不再展示,标识符仅在编辑态以小字显示);
   - 岗位设置行:名称 + 词条小字(不再用一排标签),悬停高亮;
   - 列表置于带边框圆角的 `.dlg-list` 容器内,边界清晰。
2. **编辑改为行内编辑**:点击"编辑"后,该行原地变为输入态
   (数据表:表名输入 + 保存/取消;岗位设置:名称 + 词条多选 + 保存/取消),
   编辑上下文与数据行一致,不再跳到顶部表单;顶部表单仅用于新建
   (编辑期间"添加"按钮禁用,避免误建)。
3. **操作按钮再打磨**:`.act-btn` 幽灵图标按钮(图标+文字,悬停浅底着色,
   主色/警示橙/危险红),替换原胶囊文字按钮;筛选条件管理同步更换。
4. **删除表语义**:删除表 = 同时删除该表全部岗位数据(后端由"归入默认表"
   改为直接删除);二次确认话术改为"是否要删除表并清除所有表数据?"
   (含条数与不可恢复警示);若删除的是当前选中的表,自动切回默认表并刷新岗位列表。
