# 2026-11-07 修复:in-DOM 模板自闭合标签吞并兄弟节点(编辑保存按钮消失/无法添加设置/表头多余行)

## 根因

index.html 是浏览器内解析的 in-DOM 模板:HTML 解析器**不承认组件标签的自闭合写法**
(`<el-input ... />` 对非 void 元素无效),后续兄弟元素会被当作其子元素吞入,
而 el-input/el-input-number 不渲染默认插槽,吞入的内容全部不可见。

实际后果(经无头浏览器解析器取证):
- 岗位设置创建行:名称输入框吞掉词条选择框与"添加"按钮 → 无法添加设置;
- 两个弹窗的行内编辑:输入框吞掉保存/取消按钮 → "编辑缺少保存按钮";
- 快速抓取面板:城市输入框吞掉限定词条/翻页数字段;
- 筛选条件表格:自闭合 el-table-column 相互嵌套 → 表头出现多余分组行;
- 列表行"打开"按钮吞掉删除按钮(历史"删除无反应"问题的深层原因之一)。

## 修复

1. 全量展开 27 处自闭合组件标签为显式闭合标签(正则批量 + 校验清零)。
2. 编辑态保存/取消改用 el-button 实心小按钮(主色/普通),可辨识度更高。
3. 弹窗关闭即还原编辑状态:watch gearVisible/tableVisible,未保存的编辑
   在关闭后自动复位,下次打开回到展示态。

## 验证(无头浏览器)

- 快速抓取面板 5 个输入框与翻页数字段全部可见;
- 添加设置成功(POST /gears,行数+1,测试数据已清理);
- 编辑行按钮 [保存,取消] 且词条选择框在位;
- 表编辑保存触发 PUT /api/tables/1,改名生效并已还原;
- 两弹窗关闭未保存 → 重开均为展示态;
- 筛选条件表格表头行数 = 1;unittest 64 项通过。
