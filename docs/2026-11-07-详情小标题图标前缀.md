# 详情小标题加语义图标前缀

日期:2026-11-07

## 改动(web/index.html)

三个区块小标题(14px 主题色)加语义图标前缀:

- 备注(不符合原因)→ Warning 警示图标;
- 福利标签 → Present 礼物图标;
- 职位描述 → Document 文档图标。

图标 15px、右距 6px、随标题同色(主题蓝),flex 垂直居中。

## 备注

- 纯前端改动,刷新即生效(建议 Ctrl+F5)。
- 图标组件经 ElementPlusIconsVue 全量注册,in-DOM 模板以小写名引用
  (warning/present/document 均无原生标签冲突)。
