# 2026-11-06 界面调整:薪资双输入、开始/停止合一、数据表工作区化

## 变更清单

1. **薪资范围双输入**:快速抓取与筛选条件弹窗均改为"最低 / 最高"两个输入框,
   每个输入框后缀橙色"K"(K/月),单边可缺省;仍以 "min,max" 原文存库
   (`crawl_task.salary_range` 与条件 `extras.salary`),前端校验只允许数字。
2. **开始/停止合一**:"开始抓取"与"停止抓取"合并为同一个按钮的两个形态——
   当前平台空闲时为蓝色"开始抓取",运行中变为橙色"停止抓取";
   运行状态卡片中的独立"停止"小按钮移除。
3. **数据表工作区化**:数据表选择器移到顶部工具栏第一位(当前表名常显),
   下拉框旁新增齿轮设置按钮打开管理弹窗(新建 / 重命名 / 清空 / 删除);
   **当前数据表同时决定看哪个表与新抓岗位存入哪张表**(工作表模型)。
   抓取面板中原"存入数据表"下拉移除;启动按钮下方提示当前存入表名。
   选中的数据表通过 localStorage 本地记忆,下次打开自动恢复(表被删则回默认表)。
4. **顶栏精简**:移除顶部工具栏的档位、判定、城市选择框
   (判定筛选仍可通过统计条"契合/不符"芯片使用);工具栏保留:
   数据表(+设置)、平台、搜索、排序方向开关、刷新。
5. **后端**:`POST /api/tables/{id}/clear` 清空表内岗位(默认表也可清空,表保留)。

## 验证

- 冒烟:建表→清空(空表 deleted=0)→删表;不存在表 clear 返回 404;
  无关键词启动任务返回 400。unittest 64 项全通过。
