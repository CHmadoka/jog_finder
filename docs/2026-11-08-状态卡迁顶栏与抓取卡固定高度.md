# 2026-11-08 状态卡迁顶栏与抓取卡固定高度与间距再平衡

## 三项布局重构

**1)抓取卡高度固定(两模式统一)**

- 两种模式包进固定高度内容区 `.grab-mode-area`(232px,overflow hidden):
  快速模式(岗位设置+城市+翻页)≈228px、已存条件(条件+摘要+翻页)≈229px,
  统一容器后切换模式/选择条件**卡片高度零波动**,最近任务(贴底)上方间距恒定
- CityPicker 组件改造:级联选择器移到上方、已选标签区恒定 52px 且**空态显示
  占位文案**(原先 v-hide,有无城市高度差 52px)——组件总高恒定 83px
- 已存条件的摘要区同样恒定占位 84px:无条件/未选时显示占位文案
  (原 empty-tip 与摘要互斥造成的高度波动消除)

**2)状态卡迁移:左栏 → 顶部中心**

- 左栏"运行状态"卡片整体移除,改为**顶栏中心的状态区**(absolute 居中):
  - 任一平台运行时显示,**全空闲时整个隐藏**(顶栏恢复干净)
  - 每个运行平台一段(横向):呼吸圆点 + 平台名 + 进度文本(单行 ellipsis)
    + 三个小徽章(发现 / 入库 / 跳过,跳过徽章悬停显示跳过原因明细)
  - **支持多平台并发状态同屏**(原状态卡只显示左栏当前平台)
  - 悬停平台段向下**浮层展开任务组合**(词条×城市全部,带 ✓/▶ 状态),
    浮层 absolute 不挤压任何布局
- 左栏因此只剩"发起抓取 + 最近任务"两张卡,纵向空间大幅释放

**3)间距与宽度再平衡**

- 左栏宽度 396 → 376(状态卡迁出后让位给右侧表格)
- 左栏与右栏间隔 = side 右 padding 12 + main 左 padding 2 = **14px**
  (main 上/右/下保持 10/12 与左栏一致)
- 废弃样式清理:run-head / progress-text / combo-box / counters / start-hint
  及 platformName / comboCur / skipTip 死代码(顶部状态区复用 .dot 与
  .combo-line,新增 skipTipOf 按平台取跳过明细)
