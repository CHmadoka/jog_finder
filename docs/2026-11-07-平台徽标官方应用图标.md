# 平台徽标改用官方应用图标

日期:2026-11-07

## 改动

- 三家平台徽标改用各自**官方应用图标**(App Store 512px 源图,发行主体已核对:
  Boss直聘=北京华品博睿、前程无忧=前锦网络、猎聘=同道精英),转存 128px PNG
  到 `web/`:`logo_boss.png`、`logo_51job.png`、`logo_liepin.png`。
- 删除旧的 `logo_*.ico`(Boss 仅 16px、猎聘 32px,放大到徽标会发虚)。
- 徽标 18px → 20px、圆角 6px,高分屏下不再模糊。
- 修复前程无忧徽标裂图:上一版删了 `logo_51job.ico` 但 `app.js` 仍引用 .ico,
  改为与新静态文件一致的 .png 路径。
- `<img>` 增加 `@error` 回退:图片 404/解码失败时降级为品牌色文字徽标
  (B / 51 / 猎),不再显示裂图占位。

## 备注

- 图片经 `/assets` 本地静态映射提供,离线可用、无外链。
- 纯前端 + 静态资源改动,刷新即生效(建议 Ctrl+F5)。
