# 2026-11-06 界面与命名规则调整:数据表自动命名、清空岗位库移除、组合框统一

## 变更清单

1. **数据表命名规则**:
   - 名称(显示名)缺省自动取「新数据表_n」,n 从 1 递增、取首个未被占用的序号;
   - 标识符(数据库表名风格)缺省自动取「数据表_{id}」(与行 id 对应,全局唯一);
   - `_id` 风格只用于标识符,不再用作显示名称。
2. **移除"清空岗位库"功能**:顶栏菜单项、前端 `clearAll` 与后端
   `POST /api/jobs/clear_all` 一并移除(清空数据仍可用数据表管理的"清空表")。
3. **弹窗表格再简化**:表头改为"透明背景 + 一行灰色小字 + 细底线",
   行分隔线更浅,去掉 el-table 默认的重网格与底边线(三个管理弹窗统一 `.dlg-table`)。
4. **组合框统一**:
   - 岗位设置下拉框也改为"下拉 + 齿轮设置按钮"的组合框(与数据表一致),
     原"管理设置"小字链接移除;
   - 数据表的"默认"标志移入下拉框内部、显示在下拉箭头之前
     (绝对定位于选择框内右侧,选中项文本让位避让)。

## 验证

- 冒烟:自动命名 新数据表_1/新数据表_2;手工占用「新数据表_3」后,
  下一个自动命名为 新数据表_4(正确跳过被占用序号);标识符为 数据表_{id}。
- unittest 64 项全部通过。
