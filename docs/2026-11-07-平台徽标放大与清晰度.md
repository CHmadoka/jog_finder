# 平台徽标放大到 30px 并消除模糊

日期:2026-11-07

## 改动

- 徽标尺寸 20px → **30px**(圆角 6px → 8px,文字回退字号 10px → 12px),视觉上明显更大。
- 消除模糊做了两件事:
  1. **图案紧裁**:源图四周留白很大(图案只占 52%~83%),按图案中心裁剪到
     占边长约 88%,同样尺寸下字形更大更清楚。只裁真实背景像素,不做合成填充。
  2. **1x/2x/3x 三档资源**:按 30px 分别生成 30/60/90px PNG,配合 `srcset`
     让浏览器按屏幕像素比直接取像素对齐的那张,不做运行时缩放。
- 源图从 App Store 数字资产取 **1024px 无损 PNG**(此前 512px JPEG rendition,
  白色字形边缘的 JPEG 振铃被固化进了 PNG),进一步减少毛边。
- 生成过程落到可复现脚本 `scripts/gen_logos.py`(仅 Pillow,无 numpy 依赖):
  `python scripts/gen_logos.py` 重新拉图并出三档。徽标换尺寸时须同步脚本里的
  `CSS_SIZE` 与 `.plogo` 的宽高。

## 踩坑记录

- Vue 浏览器内模板编译器**不支持跨行的属性表达式**:`:srcset="a + '…'`
  换行继续拼接会报 `Invalid or unexpected token`,整页白屏。因此把 srcset 的
  拼接挪到 `app.js` 里预生成(`logoSrcset()`),模板只做一次取值。

## 备注

- 产物已入库,离线可用,纯前端 + 静态资源改动,刷新即生效(建议 Ctrl+F5)。
- 图片加载失败时仍回退品牌色文字徽标(B / 51 / 猎),已实测。
