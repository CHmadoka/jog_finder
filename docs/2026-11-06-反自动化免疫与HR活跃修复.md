# 2026-11-06 修复说明:抓取页面变 blank / Chrome 闪退 / HR 活跃大量为空

## 问题现象

1. 点击"开始抓取"后,浏览器中打开的页面变成空白(about:blank),严重时整个 Chrome 闪退。
2. 已入库岗位的 HR 活跃状态大量显示 "-",`hr_active_text` 全部为空。

## 根因

Boss直聘页面加载反调试脚本 `browser-check-v2.js`,每约 0.5s 执行一轮检测:

- `console.log(new Date())` + `console.clear()` + `console.log(function(){})` + `console.table(50个大对象)`
  —— 依赖 console 副作用感知 DevTools/CDP 客户端(Playwright 的 `Runtime.enable` 使 console 调用
  产生可被页面感知的序列化行为);
- 另有对 `ws://127.0.0.1:<常见调试端口>/<时间戳>` 的调试端口探测。

命中后:详情页执行 `location = 'about:blank'`(整页变白,evaluate 抓到的数据随之丢失——描述/HR活跃
全空);首页因是命令行打开的窗口,`window.close()` 可成功,最后一个标签关闭后整个 Chrome 退出。
此外 Playwright `connect_over_cdp` 默认下发 `Emulation.setFocusEmulationEnabled(true)`(焦点模拟),
会使 `document.hasFocus()` 恒为真,是另一个独立的检测触发点。
经实测:详情页在加载后约 2.1s 被清空; evaluate 赶在自杀线之后完成的岗位即出现活跃/描述缺失。

## 修复

### app/browser/manager.py

- `connect_over_cdp(..., no_defaults=True)`:官方参数,不为现有默认上下文启用焦点模拟/媒体模拟,
  从源头消除焦点模拟触发点。
- 新增 `ANTIDEBUG_NEUTRALIZE_JS` 免疫补丁:置空 console 全部方法。通过
  `context.add_init_script` 在页面任何脚本(含反调试)之前注入。
- `_arm_antidebug`:对已加载页面执行一次 `reload` 使补丁在文档创建前生效。
  **不可**对已加载页面事后 `evaluate` 注入——运行中的反调试脚本会检测到 console 方法被改写,
  反而加速命中(实测教训)。
- `_launch` 冷启动后用原生 CDP WebSocket 抢先向首屏 target 注入补丁(不经 Playwright)。
- `_connect` 连接后校验 `contexts` 非空并在 2s 管线等待后复检,避免浏览器被自杀脚本关闭后
  以"浏览器未连接"的含糊报错失败。
- `get_or_open_page` 新增 `avoid_marker` 参数:复用载体标签时优先避开详情页
  (详情页会被平台自动重定向,曾导致抓取中途页面跳走、evaluate 全部失败)。

### app/platforms/*(boss/job51/liepin)

- 详情标签页改为**懒创建**(`iter_jobs` 内首次需要时才开):点击抓取不再立刻弹出空白标签,
  全部岗位已入库时不开任何标签。
- `base.py` 新增 `detail_url_marker`(Boss 为 `/job_detail/`)。
- Boss `_parse_detail`:
  - 等待逻辑改为 0.4s×12 快轮询,等活跃文案/HR 名片渲染完成,抢在反调试清理窗口内抓取;
  - 页面被清空(about:blank)时标记 `raw["blanked"]`,不入库。
- Boss `iter_jobs` finally:详情标签停在安全验证页(`_security_check`/`security-check`)时保留,
  供人工完成滑块后自动回跳;其余正常关闭。
- `_ACT_RE` 补充"N日内活跃"变体(估算函数本已支持)。

### app/scheduler/runner.py

- 不再预创建详情标签页;载体页复用传入 `avoid_marker`。
- `_process_one` 处理 `blanked`:跳过入库并写入异常面板("详情页被平台反自动化拦截(空白页)")。

### 启动.bat

- 服务日志控制台由最小化改为**显式弹出**(`cmd /c "... & pause"`),启动状态/运行日志实时可见;
  服务退出后窗口保留显示报错,按任意键关闭。

## 验证

- 免疫后详情页 21s 观察期内稳定存活,活跃文案 0.6s 内可取;Chrome 不再退出。
- 冷启动 + 热浏览器两种场景端到端跑通:登录检测 → 接口直连取得 15 岗 → Chrome 存活。
- 单元测试 46 项全部通过。
- 当前 Boss 对该账号仍有会话级风控(安全验证),需在浏览器人工完成滑块后重新开始任务,
  已入库的空活跃岗位会在重新抓到时自动补全。
