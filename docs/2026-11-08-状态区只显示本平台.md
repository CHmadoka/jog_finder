# 状态区只显示当前平台

日期:2026-11-08

## 需求

状态栏只显示本平台的(顶栏中心状态区不再混入其它运行中平台)。

## 实现

- `statusSegments` 简化为恒等于"当前选中平台"单段:切换平台时状态区整体
  随之切换,内容(圆点/平台名/进度/计数徽章/组合悬停浮层)永远只属于本平台;
- 上一轮的"其它平台简报态"(ts-mini 样式与点击切换)随之移除;
- 其它平台的运行状态可见性由**平台按钮信号灯**承载(运行=绿点呼吸,
  风控中断=红点),不丢失可观测性;
- 轮询辅助键(*_was/*_vw)不再进入段列表的计算路径(statusSegments 不再遍历
  statuses 全量键)。

## 验证

- `node --check` 通过;纯前端模板/计算属性改动,无接口变更。
