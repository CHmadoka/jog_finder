# 检索完成态绿环贴合徽标修复

日期:2026-11-08

## 问题

检索完成后平台按钮的绿色状态环(`.top-plat.st-done` 的 box-shadow)没有贴合
logo,环与徽标之间有缝隙。

## 根因

`.top-plat` 容器是 block 盒,内部 `.plogo`(30×30 的 inline-flex)参与**行内
布局**:行盒受字体 strut 影响被撑出额外 leading,容器实际高度比徽标大 2~4px;
而状态环(box-shadow)画在**容器**外缘而非徽标边缘 → 环与 logo 之间出现空隙
(垂直方向尤明显)。

## 修复

容器改为 `display: flex; line-height: 0`:徽标成为 flex item,不再参与行盒
排版,容器尺寸严格等于徽标 30×30(与 `scripts/gen_logos.py` 的 CSS_SIZE 约定
一致),box-shadow 环随之完全贴合徽标边缘;悬停/选中的 transform 放大与徽标、
环整体等比缩放,贴合关系不变。

## 验证

纯 CSS 改动(单条规则),无 JS/接口变更;刷新页面即可观察完成态绿环贴合效果。
