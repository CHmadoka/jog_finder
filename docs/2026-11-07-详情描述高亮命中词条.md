# 详情描述高亮命中词条(旧数据同样生效)

日期:2026-11-07

## 需求

浏览岗位详情时,高亮显示匹配到的词条;旧数据也要处理。

## 方案:展示时动态扫描(零迁移,旧数据天然生效)

词条来源 = 岗位记录自带的 `keyword` 字段(该任务全部搜索词条,顿号/
竖线分隔)。实测存量数据 771 条该字段**全部有值**,因此不做任何回填/
迁移——前端在打开详情时动态扫描,新旧数据行为一致。

## 实现

- `web/app.js`
  - `jobKeywords`:keyword 按 顿号/逗号/竖线/分号 拆分去重;
  - `hitKeywords`:出现在**标题或描述**中的词条(标签展示);
  - `highlightedDesc`:描述整段先 HTML 转义(防 XSS),再按词条替换为
    `<mark>`——**长词优先**(避免"文员"截胡"仓库文员"),仅替换描述中
    实际出现的词条;词条经正则转义,含特殊字符(如 C++)亦正确。
- `web/index.html`
  - 详情抽屉标签区新增「命中: 词条」标签(淡黄,悬停说明);
  - 描述区改 `v-html` 渲染高亮结果(空描述仍显示占位);
  - `mark` 样式:淡黄底/加粗/圆角。

## 验证

- 68 项测试全部通过;`node --check` 通过。

## 备注

- 纯前端改动,刷新页面即生效。
- 高亮范围:详情抽屉的职位描述;命中判定含标题(标签可见)。
