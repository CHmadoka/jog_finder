# 2026-11-08 异常胶囊去杂色边框与悬停改阴影

## 改动

- 「抓取异常」胶囊去掉淡红杂色边框(`border: 1px solid #f3c1c1`),
  与品牌区/状态区白色圆角胶囊同款的无边框 + 阴影风格;
- 悬停取消 `translateY(-1px)` 位移偏移,改为**加深阴影**表达浮起
  (基础 `0 4px 14px / .12`,悬停 `0 6px 18px / .25`);
- `transition` 由 `all` 收窄为 `box-shadow`。

## 验证

- 纯 CSS 改动,结构无变化。

## 备注

- 纯前端改动,刷新即生效(建议 Ctrl+F5)。
